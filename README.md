# Conloca — лендинг

## Что это

Это репозиторий маркетингового лендинга продукта Conloca. Сам Conloca — это
Git-нативная headless CMS для сайтов на Astro: контент хранится как MDX- и
JSON-файлы прямо в репозитории клиента, разработчики работают с ним в IDE, а
нетехнические редакторы получают визуальный редактор — и те, и другие пишут в
одни и те же файлы. Продукт продаёт себя историей изменений в Git, обзором
правок через pull request и локализацией контента.

Лендинг — полностью статическая страница: никакого сервера в рантайме нет,
`bun run build` собирает готовый набор файлов в папку `dist/`.

## Статус проекта

Собран и запушен в `main`:

- вёрстка всех секций страницы, сделанная по дизайну, вытащенному из Figma;
- анимации, включая эффект прокрутки, при котором карточки трёх функций
  продукта закрепляются на экране и сменяют друг друга внахлёст (это
  отдельная, самая заметная анимация на странице);
- Lottie-баннер с панелью управления языками — тот самый анимированный ролик,
  который прислал дизайнер.

Не готово:

- часть решений по дизайну команда приняла сама, на своё усмотрение — список
  таких решений и оставшиеся открытые вопросы к дизайнеру собраны в
  [`docs/QUESTIONS-DESIGNER.md`](docs/QUESTIONS-DESIGNER.md);
- вёрстка на мобильных и планшетных экранах проверена только выборочно, не
  полным прогоном по всем разрешениям.

## Для дизайнера

В файле [`docs/QUESTIONS-DESIGNER.md`](docs/QUESTIONS-DESIGNER.md) собраны все
места, где макет или присланные файлы не дали однозначного ответа. Часть из
них команда решила сама, на своё усмотрение — эти решения тоже перечислены в
файле; остальные нужно закрыть вам. Отвечать можно прямо там, одной строкой
под вопросом.

Исходный макет в Figma:
https://www.figma.com/design/OxxksZFS8hzKoFTeSRdFGs/Conloca?node-id=40002391-9972

Живой предпросмотр появится здесь после деплоя.

## Для разработчиков

| Что | Выбор |
| --- | --- |
| Пакетный менеджер | bun |
| Сборщик | Vite через `rolldown-vite` (сборщик на Rust, движок Oxc) |
| Линтер | `oxlint` (ESLint не используется) |
| UI-фреймворк | React |
| Стили | Tailwind CSS |
| Компоненты | shadcn/ui |
| Анимации | `motion` + `@lottiefiles/dotlottie-react` |

Точные версии — в `package.json`; список выше не дублирует их специально,
чтобы не разъезжаться при обновлениях.

```bash
bun install
bun run dev     # сервер разработки
bun run build   # сборка в dist/
bun run lint    # линт
```

Полное техническое описание — как работает статическая сборка, правила для
анимаций и прочее — в [`AGENTS.md`](AGENTS.md).

## Структура репозитория

- `src/components/sections/` — секции страницы (Hero, ThreeFeatures,
  FeatureGrid, Pricing и другие) — то, что реально видно на странице.
- `src/components/ui/` — базовые компоненты shadcn/ui.
- `public/` — статические ассеты, включая Lottie-баннер и его плеер.
- `docs/QUESTIONS-DESIGNER.md` — вопросы дизайнеру, живой файл.
- `docs/figma/` — дизайн-спека, вытащенная из Figma при сборке страницы.
